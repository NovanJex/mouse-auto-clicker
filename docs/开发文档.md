# 鼠标连点器 v2.0 — 开发文档

> **架构**: Tauri v2 (Rust 后端) + React 18 + TypeScript + Vite
> **UI 设计**: Google Stitch (AI 生成) + Tailwind CSS + Material Design 3 风格
> **策略**: 新目录从零搭建，功能 1:1 对等 v1.2.1

## 一、为什么 Tauri 能做到 5MB 的 exe 直接运行？

这是选择 Tauri 的核心原因。对比传统方案：

| 方案 | 包大小 | 运行时依赖 | 用户操作 |
|------|--------|-----------|---------|
| WPF 自包含 | ~155 MB | 无（内嵌 .NET） | 下载大文件 |
| WPF 框架依赖 | ~1.5 MB | 需安装 .NET 8 (55MB) | 先装运行时再运行 |
| Electron | ~80 MB | 内嵌 Chromium | 下载大文件 |
| **Tauri 框架依赖** | **~3-5 MB** | **Windows 自带 WebView2** | **直接双击 exe** |

**原理**: Windows 10 1803+ / Windows 11 已将 WebView2（基于 Edge/Chromium）预装到系统中。Tauri 不捆绑浏览器引擎，而是调用系统的 WebView2 作为渲染层。Rust 编译的二进制本身极小（~3MB），加上少量前端资源（HTML/CSS/JS），最终安装包仅 5-8 MB。

用户下载后**双击 exe 直接运行**，不需要任何预安装步骤。

```bash

# 2. 进入项目目录
cd auto-clicker-v2

# 3. 安装前端依赖
pnpm install

# 4. 安装 Zustand 状态管理
pnpm add zustand

# 5. 验证 Tauri 开发环境
pnpm tauri dev
# → 应看到空白的 React 页面在桌面窗口中打开

# 6. 验证 Rust 编译
cargo build
# → 零错误零警告
```

## 三、技术架构

### 3.1 整体分层

```
┌──────────────────────────────────────────┐
│          React 18 + TypeScript            │  ← 前端层
│  Zustand Stores → Components → invoke()   │
├──────────────────────────────────────────┤
│        Tauri IPC Bridge (JSON)            │  ← 通信层
│  tauri::command / emit events             │
├──────────────────────────────────────────┤
│         Rust Services (业务逻辑)           │  ← 服务层
│  MouseSim / KeyboardHook / Scheduler...   │
├──────────────────────────────────────────┤
│     Win32 API Wrappers (windows crate)    │  ← 系统层
│  SendInput / PostMessage / SetWindowsHook │
├──────────────────────────────────────────┤
│  Message Pump Thread (隐藏窗口+消息循环)    │  ← 基础设施
└──────────────────────────────────────────┘
```

### 3.2 数据流

```
用户操作 → React 组件 → Zustand action → invoke(cmd, args)
    │                                           │
    │                                    Tauri IPC (JSON)
    │                                           │
    │                                    Rust tauri::command
    │                                           │
    │                                    Rust Service (处理逻辑)
    │                                           │
    │                                    Win32 API (windows crate)
    │                                           │
    ▼ (Tauri Event 推送) ◄──────────────────────┘
Zustand store 更新 → React 重新渲染
```

## 五、Material Design 3 UI 布局设计

### 5.1 设计理念

基于 Google Material Design 3（Material You）设计语言，采用以下核心模式：

- **卡片式布局**: 每个功能模块独立一张 Material Card
- **Segmented Button**: 互斥选项（点击模式、间隔模式、位置模式）
- **Filled Button**: 主要操作（开始/停止）
- **Outlined Button**: 次要操作（选取坐标、录键、添加任务）
- **Icon Button**: 行内操作（删除、刷新）
- **Switch**: 开关控制（键盘触发启用/禁用）
- **Chip**: 标签显示（绑定项、任务项）
- **Snackbar**: 轻量提示（操作结果反馈）

## 六、Rust 模块设计

### 6.1 关键模块：消息泵线程

WH_KEYBOARD_LL 和 WH_MOUSE_LL 钩子必须运行在有 Windows 消息泵的线程上。Tauri 的 UI 线程被 WebView 占用，需要创建独立的消息泵线程。

```rust
// message_pump.rs — 核心组件
use std::sync::mpsc;
use std::thread;

pub enum PumpEvent {
    Keyboard { vk_code: u32, is_down: bool, is_injected: bool },
    Mouse { event_type: MouseEventType, x: i32, y: i32, is_injected: bool },
    Hotkey(i32),
}

pub struct MessagePump {
    thread: Option<thread::JoinHandle<()>>,
    shutdown_tx: Option<mpsc::Sender<()>>,
}

impl MessagePump {
    pub fn start() -> (Self, mpsc::Receiver<PumpEvent>) {
        let (event_tx, event_rx) = mpsc::channel();
        let (shutdown_tx, shutdown_rx) = mpsc::channel();

        let tx = event_tx.clone();
        let thread = thread::spawn(move || {
            // ① 创建隐藏窗口 (HWND_MESSAGE)
            // ② 安装 WH_KEYBOARD_LL + WH_MOUSE_LL 钩子
            // ③ RegisterHotKey F6-F10 到隐藏窗口
            // ④ GetMessage 消息循环
            // ⑤ 钩子回调: 解析事件 → tx.send() → CallNextHookEx
            // ⑥ WM_HOTKEY: tx.send(PumpEvent::Hotkey(id))
            // ⑦ shutdown_rx 收到信号 → PostQuitMessage → 清理
        });

        (MessagePump { thread: Some(thread), shutdown_tx: Some(shutdown_tx) }, event_rx)
    }
}
```
