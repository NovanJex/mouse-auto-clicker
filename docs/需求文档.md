# 鼠标连点器 v2.0 — 需求文档

> **项目**: 鼠标连点器 (AutoClicker) v2.0
> **架构**: Tauri v2 (Rust 后端) + React 18 + TypeScript (前端)
> **定位**: Windows 桌面鼠标自动点击工具，独立新建项目
> **参考**: 现有 v1.2.1 版本的全部功能

---

## 一、项目背景

### 1.1 为什么重写

当前版本基于 C# 12 / .NET 8 + WPF 构建，功能成熟稳定。选择 Tauri + React 重写的核心原因：

| 对比维度 | WPF 自包含 | Tauri 框架依赖 | 提升 |
|----------|-----------|---------------|------|
| 安装包大小 | ~155 MB | **~5-8 MB** | **缩小 95%+** |
| 运行时依赖 | .NET 8 Runtime（~55MB） | Windows 10 自带 WebView2 | 零额外安装 |
| 启动方式 | 需安装或解压 | **双击 exe 直接运行** | 即开即用 |
| UI 可定制性 | XAML 控件模板（有限） | CSS + React 组件（极致灵活） | 现代化 UI |
| 内存占用 | ~80-120 MB | ~30-50 MB | 更轻量 |
| 跨平台潜力 | 无（Windows 专属） | 架构支持（当前仅 Win32 API） | 未来可扩展 |

**核心卖点**: 用户下载一个 **5MB 的 exe** 文件，**双击即可运行**，无需安装任何运行时。Windows 10（1803+）及 Windows 11 自带的 WebView2 组件已满足所有依赖。

### 1.2 开发目标

1. **功能对等**: 完整实现 v1.2.1 全部 10 项核心功能
2. **独立新项目**: 在干净的新目录中从零搭建，不依赖旧代码
3. **现代 UI**: 采用 Material Design 3 设计语言，视觉体验优于原版
4. **小体积**: 框架依赖模式安装包 ≤ 8 MB
5. **零门槛运行**: 下载 exe → 双击 → 直接使用

## 二、功能需求

### FR-01：鼠标自动连点引擎 ★P0

在指定屏幕坐标以可调间隔自动执行鼠标点击。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-01.1 | 点击模式 | 左键单击、左键双击、右键单击、中键/滚轮单击 |
| FR-01.2 | 间隔模式 | 毫秒模式（50-60000ms）、CPS 模式（每秒 1-100 次）、长按模式（按住持续时长） |
| FR-01.3 | 位置模式 | 跟随光标（在当前鼠标位置点击）/ 固定坐标（指定屏幕 X/Y 像素） |
| FR-01.4 | 重复次数 | 1-999 次，或无限循环（重复=0） |
| FR-01.5 | 高精度定时 | 延迟 <15ms 自旋等待，>=15ms 异步延迟，timeBeginPeriod(1) 提升系统精度 |
| FR-01.6 | 多显示器 | 归一化坐标（0-65535）映射虚拟桌面，跨显示器兼容 |
| FR-01.7 | 启停控制 | UI 主按钮 + F6/F7 全局热键 |
| FR-01.8 | 状态反馈 | 实时显示运行/停止状态、点击次数 |

**验收**: 设置 100ms 间隔+固定坐标+左键 → 每秒 10 次点击；CPS=50 → 每秒 50 次点击

### FR-02：无光标点击 ★P0

向目标窗口直接投递鼠标消息，物理光标完全不动。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-02.1 | 窗口定位 | WindowFromPoint 获取目标坐标所在窗口句柄 |
| FR-02.2 | 坐标转换 | ScreenToClient 屏幕坐标→窗口客户区坐标 |
| FR-02.3 | 消息投递 | PostMessage 直接投递 WM_LBUTTONDOWN/UP/D BLCLK 等消息 |
| FR-02.4 | 模式支持 | 四种点击模式全部支持 PostMessage 路径 |
| FR-02.5 | 降级回退 | 目标无窗口时自动回退 SendInput 原子批次方案 |

**验收**: 对记事本触发 → 出现输入效果，鼠标指针不移动；桌面触发 → 自动回退正常

### FR-03：多键位绑定触发 ★P0

不同键盘按键绑定不同屏幕坐标和点击模式，按下即触发。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-03.1 | 全局钩子 | WH_KEYBOARD_LL 系统级键盘钩子，后台/非激活窗口可用 |
| FR-03.2 | O(1) 查找 | HashMap/Dictionary 从键码→绑定信息，多键位并发支持 |
| FR-03.3 | 注入过滤 | 检测 LLKHF_INJECTED 标志位，过滤模拟按键 |
| FR-03.4 | 重复抑制 | HashSet 跟踪已按下按键，WM_KEYDOWN 已存在键时忽略 |
| FR-03.5 | 按键录制 | 临时监听模式，捕获下一个非注入按键返回其虚拟键码 |
| FR-03.6 | 绑定管理 | 添加（同键覆盖）、删除绑定，列表查看 |
| FR-03.7 | 防误触 | 坐标选取器打开期间自动抑制触发 |
| FR-03.8 | 独立开关 | 启用/禁用复选框，独立控制键盘触发功能 |

**验收**: 空格→(100,200)+左键 → 按空格触发；覆盖绑定空格→新坐标 → 新绑定生效

### FR-04：鼠标宏录制与回放 ★P1

录制用户鼠标操作序列，按原始时间戳精确回放。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-04.1 | 全局录制 | WH_MOUSE_LL 系统级鼠标钩子，F8 开始/停止 |
| FR-04.2 | 事件类型 | LeftDown/Up、RightDown/Up、MiddleDown/Up（跳过 Move 降低数据量） |
| FR-04.3 | 高精度时间戳 | Stopwatch/QueryPerformanceCounter 记录相对毫秒时间 |
| FR-04.4 | 注入过滤 | LLMHF_INJECTED 标志过滤，防止录制-回放反馈循环 |
| FR-04.5 | 单次回放 | F9 按原始时间间隔精确重现所有事件 |
| FR-04.6 | 循环回放 | F10 循环播放，1-999 次可配置，支持中途停止 |
| FR-04.7 | 持久化 | RecordingSession 序列化 JSON 保存到 %LocalAppData%/AutoClicker/ |
| FR-04.8 | 实时反馈 | 录制中显示事件计数和时长；回放中显示进度 |

**验收**: 录制 5 次点击 → 事件计数=5；F9 回放重现序列；F10 循环 3 次自动停止

### FR-05：定时点击任务 ★P1

创建按预设延迟执行的点击任务，顺序执行。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-05.1 | 任务要素 | 标签名称 + 延迟数值 + 时间单位（秒/分/时）+ 目标坐标 + 点击模式 |
| FR-05.2 | 顺序执行 | 按添加顺序依次执行，每任务等待指定延迟后点击 |
| FR-05.3 | 可取消 | 延迟以 1 秒粒度分块，每秒检查取消标志 |
| FR-05.4 | 无光标点击 | 使用 PostMessage 路径，不干扰用户正常操作 |
| FR-05.5 | 独立运行 | 与手动连点引擎互不干扰，可同时工作 |
| FR-05.6 | 状态通知 | 任务开始/完成/全部完成/手动停止时推送事件 |
| FR-05.7 | 任务管理 | 添加、删除、列表查看 |

**验收**: 3 个任务(2s/5s/3s延迟) → 2s、7s、10s 各执行一次；中途停止立即中断

### FR-06：全局热键 ★P0

系统级热键，任何前台应用均可触发。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-06.1 | API | RegisterHotKey Win32 API，MOD_NOREPEAT 防弹跳 |
| FR-06.2 | 映射 | F6→开始/停止连点、F7→停止连点、F8→录制、F9→回放、F10→循环回放 |
| FR-06.3 | 路由 | WM_HOTKEY(0x0312) 消息，wParam 为热键 ID(1-5) |
| FR-06.4 | 恢复 | 锁屏/休眠解锁后自动重新注册 |
| FR-06.5 | 清理 | 退出时 UnregisterHotKey 全部注销 |

**验收**: 记事本前台+按 F6 → 连点器响应；锁屏解锁后 F6 仍有效

### FR-07：系统托盘 ★P1

托盘图标常驻，支持右键菜单和关闭到托盘。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-07.1 | 图标 | 通知区域显示应用图标 + "鼠标连点器"提示 |
| FR-07.2 | 左键 | 单击托盘图标 → 显示/恢复窗口 |
| FR-07.3 | 右键菜单 | "显示窗口" + "退出"两个菜单项 |
| FR-07.4 | 关闭行为 | 点 X → 确认对话框："退出" / "最小化到托盘" / "记住选择" |
| FR-07.5 | 清理退出 | 停止引擎 → 保存设置 → 移除图标 → 退出进程 |

**验收**: 托盘图标出现 + 右键菜单；X 关闭→对话框→最小化到托盘；记住选择下次直接生效

### FR-08：坐标选取器 ★P1

全屏覆盖层，点击任意位置返回屏幕坐标。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-08.1 | 覆盖层 | 全屏半透明深色(#22000000)，十字准星光标 |
| FR-08.2 | 捕获 | 点击返回实际屏幕坐标（含 DPI 缩放处理） |
| FR-08.3 | 取消 | ESC 键关闭，不返回坐标 |
| FR-08.4 | 窗口属性 | 无装饰、总在最前、无任务栏 |

**验收**: 点击"选取"→全屏变暗→点击某处→坐标回填；ESC→关闭不变

### FR-09：配置持久化 ★P0

所有设置自动保存/加载。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-09.1 | 路径 | %LocalAppData%/AutoClicker/settings.json |
| FR-09.2 | 内容 | 全部设置：点击配置、键位绑定、定时任务、托盘偏好、录制数据 |
| FR-09.3 | 时机 | 设置变更自动保存（debounce 500ms）+ 退出同步保存 |
| FR-09.4 | 容错 | JSON 损坏/不存在 → 静默使用默认值，不弹错误框 |
| FR-09.5 | 序列化 | serde + serde_json（Rust），零样板代码 |

**验收**: 改设置→关应用→重开 → 设置保留；损坏 JSON → 无报错启动

### FR-10：应用生命周期 ★P0

单实例运行、会话恢复、干净退出。

| 子项 | 需求 | 详细说明 |
|------|------|---------|
| FR-10.1 | 单实例 | 第二个实例启动 → 激活已有窗口，自身退出 |
| FR-10.2 | 会话恢复 | 解锁后自动重新注册热键 |
| FR-10.3 | 干净退出 | 停止任务→注销热键→卸载钩子→保存设置→移除托盘→退出 |

**验收**: 双击 exe → 激活现有窗口；解锁后热键恢复；退出后进程消失

## 三、非功能需求

### NFR-01：性能

| 指标 | 要求 |
|------|------|
| 点击抖动 | 100 CPS（10ms 间隔）下 < 2ms |
| 录制精度 | 时间戳 < 1ms |
| UI 响应 | 100 CPS 期间 UI 不卡顿 |
| 钩子延迟 | 回调处理 < 1ms，不阻塞系统输入链 |
| 应用大小 | 框架依赖安装包 ≤ 8 MB |

### NFR-02：安全

- 所有 Win32 API 封装在 Rust 后端，前端零系统调用
- IPC 参数 Rust 端校验（坐标、延迟、CPS 范围）
- asInvoker 权限，不请求管理员权限

### NFR-03：可靠性

- 钩子异常断开自动重装
- 设置文件损坏静默回退默认值
- PostMessage 失败自动降级 SendInput
- Rust panic 不导致进程崩溃

### NFR-04：分发

- **框架依赖版**（推荐）: 利用系统 WebView2，5-8 MB，双击即运行
- **NSIS 安装包**: 中文安装向导，开始菜单 + 桌面快捷方式
- **平台**: Windows 10 1803+ x64（WebView2 Evergreen 最低要求）

### NFR-05：可维护性

- Rust + TypeScript 双端严格类型，禁用 `any`
- 每个功能域独立 Zustand store + 组件目录
- 中文代码注释
